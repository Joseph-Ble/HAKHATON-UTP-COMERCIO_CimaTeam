Decisiones vigentes de EntreVecinos

- Desarrollo autorizado por el usuario. La auditoría inicial queda como antecedente.
- React Native con Expo y JavaScript. No TypeScript, Capacitor ni WebView.
- El usuario retiró la restricción de 48 horas. Se trabaja por hitos funcionales sin un límite artificial de tiempo.
- Supabase puede configurarse después. La primera entrega usa persistencia local y una implementación remota preparada; no se afirma sincronización entre dispositivos sin conectarla.
- El usuario pidió una interfaz de producto sin rótulos «Demo». Se conserva una explicación exacta de los datos de ejemplo y el almacenamiento local en Ajustes.
- Los reportes de ejemplo son preventivos o archivados, con fecha visible. No se presentan emergencias ficticias como alertas activas.
- Portada con tres módulos; solidaridad conserva vender/comprar/intercambiar y ofrece acceso visible a ayuda sin dinero.
- Coordinación privada breve con propuestas, respuestas y ofertas de ayuda; el contacto externo es opcional y consentido.
- Moderación y edición de contenido institucional en la misma aplicación. Publicaciones de inseguridad y sus ediciones requieren revisión previa.
- Fotos, video, GPS, pagos, chat continuo, push e IA se reservan para una ampliación. Ninguno es necesario para probar los flujos principales.
- La APK interna incorpora JavaScript y no depende de Metro. La firma de desarrollo sirve para pruebas, no para publicar en Google Play.
- Código y commits locales. Ningún push ni despliegue público está autorizado por este documento.
